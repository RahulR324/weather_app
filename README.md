# **🌦️ Weather App (Full Stack)**

A modern, responsive **Weather Application** built using **Node.js, Express, and Vanilla JavaScript**, powered by the OpenWeather API.
This project provides real-time weather updates, hourly forecasts, and a 5-day forecast with a clean and user-friendly UI.

---

## **🚀 Features**

* 🔍 Search weather by city name
* 📍 Auto-detect user location (Geolocation)
* 🌡️ Current weather details (temperature, humidity, wind speed)
* ⏱️ Hourly forecast (interactive slider)
* 📅 5-day weather forecast
* 🌙 Dynamic greeting based on time
* 🎨 Responsive modern UI design
* ⚡ Fast API integration using Express backend
* 🔒 Secure API handling with environment variables

---

## **🛠️ Tech Stack**

### **Frontend**

* HTML5
* CSS3 (Flexbox, Grid, Responsive Design)
* JavaScript (ES6)

### **Backend**

* Node.js
* Express.js

### **API**

* OpenWeather API
